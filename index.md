# Политика конфиденциальности приложения «Лунный сад»

**Дата вступления в силу:** 22 октября 2026 года

## 1. Общие положения

Настоящая Политика конфиденциальности определяет порядок обращения с информацией пользователей мобильного приложения «Лунный сад» (далее — «Приложение»).

Разработчик Приложения: [ФИО разработчика].

## 2. Сбор персональных данных

Приложение не собирает, не запрашивает и не передаёт персональные данные пользователей.

Для использования Приложения не требуется регистрация, создание учётной записи или предоставление личной информации.

## 3. Хранение данных

Приложение может сохранять игровые настройки и прогресс непосредственно на устройстве пользователя.

Эти данные используются исключительно для работы Приложения и не передаются разработчику или третьим лицам средствами Приложения.

## 4. Сторонние сервисы

Приложение не использует сторонние сервисы аналитики, рекламы или отслеживания пользователей.

## 5. Безопасность данных

Приложение не осуществляет передачу пользовательских данных на внешние серверы.

Пользователь может удалить локальные данные Приложения через настройки операционной системы Android.

## 6. Изменения политики

Разработчик оставляет за собой право обновлять настоящую Политику конфиденциальности при изменении функциональности Приложения.

Актуальная версия документа публикуется по ссылке, указанной на странице Приложения.
